<objective>
Wire the existing `tagging/route_area_tagging.py` LLM pipeline as a post-scrape stage that updates D1's `route_tags` and `area_tags` JSON columns instead of writing back to the source JSON files alone. Build `tagging/d1_tag_sync.py` — a thin transformer that reads a `*_routes_tagged.json` file produced by the existing tagger and generates batched, idempotent UPDATE statements against the D1 schema. This decouples scrape cost from LLM cost (D-07) and makes tagging re-runnable without re-importing the whole dataset (D-08).

Purpose: Without this glue, every monthly scrape would have to either inline the LLM tagging step (slow, expensive, coupled) or re-run the full Plan 02 import to update tags. With this plan, the operator runs: (1) async scraper → (2) `import_to_d1` for new/changed routes → (3) `route_area_tagging` (existing, unchanged) → (4) `d1_tag_sync` to push tags into D1. Each stage is independently restartable.

Output: `tagging/d1_tag_sync.py`, unit tests, fixture, and a README section documenting the 4-stage pipeline.
</objective>

       ```python
       def build_route_tag_updates(data: list[dict]) -> list[tuple[str, str]]:
           """
           Walk all areas → routes; emit (route_d1_id, route_tags_json_string) for routes
           that have non-empty route_tags. Skip empty/missing tags.
           Returns a list sorted by route_d1_id for deterministic SQL output.
           """
           out: list[tuple[str, str]] = []
           for area in data or []:
               for route in area.get("routes", []) or []:
                   tags = route.get("route_tags")
                   if not tags:  # None or empty dict
                       continue
                   if isinstance(tags, dict) and len(tags) == 0:
                       continue
                   rid = resolve_route_d1_id(route)
                   if not rid:
                       continue
                   tags_json = json.dumps(tags, sort_keys=True, ensure_ascii=False)
                   out.append((rid, tags_json))
           # Deduplicate (same route_id appearing twice) — keep last
           dedup: dict[str, str] = {}
           for rid, tj in out:
               dedup[rid] = tj
           return sorted(dedup.items())
       ```

       Implementation outline:
       ```python
       def chunk_updates(table, column, key_column, updates, max_bytes=UPDATE_BATCH_BYTES):
           if not updates:
               return []
           statements: list[str] = []
           buf_when: list[str] = []
           buf_keys: list[str] = []
           buf_size = 0
           HEADER = f"UPDATE {table} SET {column} = CASE {key_column} "
           FOOTER_TEMPLATE = " END WHERE {key} IN ({keys});"

           def flush():
               nonlocal buf_when, buf_keys, buf_size
               if not buf_when:
                   return
               sql = HEADER + " ".join(buf_when) + FOOTER_TEMPLATE.format(
                   key=key_column,
                   keys=",".join(buf_keys),
               )
               statements.append(sql)
               buf_when, buf_keys, buf_size = [], [], 0

           for key, value in updates:
               key_sql = sql_quote(key)
               value_sql = sql_quote(value)
               when_clause = f"WHEN {key_sql} THEN {value_sql}"
               # Estimated incremental size: when_clause + ", " + key_sql for the IN list
               inc = len(when_clause) + len(key_sql) + 4
               # If adding this would overflow, flush first
               header_footer = len(HEADER) + len(FOOTER_TEMPLATE.format(key=key_column, keys=""))
               if buf_size and (buf_size + inc + header_footer) > max_bytes:
                   flush()
               buf_when.append(when_clause)
               buf_keys.append(key_sql)
               buf_size += inc

           flush()
           return statements
       ```

    7. **`generate_sync_sql(input_path: Path | str, output_path: Path | str) -> str`**:
       ```python
       def generate_sync_sql(input_path, output_path):
           input_path = Path(input_path)
           output_path = Path(output_path)
           with open(input_path, "r", encoding="utf-8") as f:
               data = json.load(f)
           route_updates = build_route_tag_updates(data)
           area_updates = build_area_tag_updates(data)
           lines: list[str] = [
               f"-- Generated tag sync for {input_path.name}",
               f"-- Routes: {len(route_updates)} | Areas: {len(area_updates)}",
               "",
           ]
           for stmt in chunk_updates("routes", "route_tags", "route_id", route_updates):
               lines.append(stmt)
           for stmt in chunk_updates("areas", "area_tags", "area_id", area_updates):
               lines.append(stmt)
           sql = "\n".join(lines) + "\n"
           output_path.parent.mkdir(parents=True, exist_ok=True)
           output_path.write_text(sql, encoding="utf-8")
           return sql
       ```
