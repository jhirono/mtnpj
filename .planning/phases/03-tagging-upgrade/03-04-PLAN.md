## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| enriched JSON → OpenAI Batch API | Route descriptions + tick comments (user-generated text) sent to OpenAI; tick text may contain PII (names, locations) though unlikely in climbing notes |
| OpenAI Batch API → tagged JSON | LLM output tags are written to tagged JSON; tags that fail validate_tags() are stripped by existing pipeline |
| tagged JSON → local D1 SQL | sql_quote() in d1_tag_sync.py handles apostrophes in tag values (T-05-01 from Phase 01) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Information Disclosure | Route descriptions + tick comments sent to OpenAI | accept | Data is scraped from public Mountain Project pages; no private user PII beyond tick text already public on MP. OpenAI data retention policies apply. |
| T-03-12 | Tampering | LLM hallucinated tag categories | mitigate | validate_tags() in route_area_tagging.py strips tags not in ALLOWED_TAGS dict before writing to JSON. Spot-check in Task 2 catches systematic issues. |
| T-03-13 | Denial of Service | Full 2,969-route batch — unexpected cost overrun | mitigate | Estimated cost confirmed at <$1 for all models. OPENAI_API_KEY spend limit should be set in OpenAI dashboard. Log displays cost estimate before submission. |
| T-03-14 | Tampering | sql_quote() missing for tick comment content in tag sync | accept | Tick comments flow through route_tick_comments → LLM → route_tags (structured JSON). Tag values are the LLM-generated strings, not raw tick text. sql_quote() in chunk_updates() handles any apostrophes in the LLM output. |
