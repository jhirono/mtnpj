## Milestone Summary

**Key Decisions:**
- Cloudflare D1 + Pages + Workers (Hono) — chosen over Firebase/Supabase/Turso for zero-cost, zero-ops, edge-native stack
- 9 boolean type columns (is_sport, is_trad, is_aid, is_ice, is_alpine, is_mixed, is_tr, is_boulder, is_snow) — avoids JOIN overhead, enables simple filter queries
- Async HTTP via httpx + asyncio.Semaphore for non-JS pages; Selenium kept for login-gated comment + stats scraping
- Stable route_id from MP URL numeric segment — prerequisite for incremental diff scraping
- Import batching ≤100KB per D1 statement — stays within Cloudflare D1 batch size limit
- type parameter whitelisted before SQL column interpolation — SQL injection blocked at zod layer
- Materialized path on areas from URL slugs — enables hierarchy traversal without recursive CTE

**Issues Resolved:**
- BFS flooded by /area/classics/ links → fixed with numeric-ID-only href filter
- `?print=1` printer-friendly link counted as sub-area → fixed with query-param exclusion
- Aid/clean-aid grades missing (pure aid showed wrong YDS grade) → fixed h2 text node parsing
- Ice (WI/AI) and mixed (M) grades dropped for multi-discipline routes → added token-level regex matching
- FK constraint failures during bulk D1 import → PRAGMA foreign_keys=0 + topological sort of areas
- Frontend DataService hard-coded sport/trad filenames → deleted, replaced with Worker API client

**Issues Deferred:**
- 01-01 T03: Full Yosemite NP smoke test (Valley South Side + El Capitan validated instead)
- route_lr (left-right sort order) requires Selenium — always 0 in --no-selenium mode
- Tick comments and route comments require Selenium login session

**Technical Debt:**
- Import SQL files in worker-api/ were generated before the FK fix — need regeneration for any fresh import
- grade_to_numeric returns NULL for pure aid/ice/mixed grades (no numeric sort for WI5+, A3, etc.)
